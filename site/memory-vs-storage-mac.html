Memory vs storage on Mac, in plain English.

Both are measured in gigabytes, and macOS warns you about both, so they're easy to mix up. Memory is the desk you work on. Storage is the filing cabinet. Here's how they differ, and how one can run out because of the other.

The short version

Memory (RAM, which Apple calls unified memory) holds the apps and files you have open right now, and empties when you restart. Storage (the SSD) keeps everything you've saved, even when the Mac is off. Check memory in Activity Monitor › Memory, and storage in System Settings › General › Storage. When memory runs short, macOS borrows storage as swap, so a nearly full disk can cause memory warnings too.

Memory is fast and temporary: it's where the apps you have open, and the files they're working on, live while you use them. Storage is slower and permanent: it's where everything waits until you open it again. A Mac with 16 GB of memory and 512 GB of storage can have 16 GB of things open at once, and keep 512 GB of things saved.

How to check each one

Memory

  1. See how much you have. Choose Apple menu › About This Mac. It's listed as Memory.
  2. See how it's being used. Open Activity Monitor from Applications › Utilities and click Memory. The Memory Pressure graph at the bottom matters more than the numbers: green is fine, yellow is busy, red means the Mac needs more than it has.

Storage

Open System Settings › General › Storage. The bar shows how much is used and by what. How to check Mac storage covers four more ways, including Terminal.

Where they meet: swap

When open apps need more memory than the Mac has, macOS moves some of it out to the disk, into swap files, and brings it back when it's needed. That's normal, and it's why a Mac doesn't crash when memory fills up. But it means memory can take storage.

On the MacBook Pro this guide was written on, with 48 GB of memory, macOS had 22.5 GB of swap files on the disk after a long day of work. On a Mac with less memory, or more apps open, it can be more. Swap goes away when you restart.

This is why the two warnings are connected. If the disk is nearly full, macOS has nowhere to put swap, and you can see “Your system has run out of application memory” even though the real problem is storage. Free up disk space and the warning usually stops. How to free up space on Mac is the checklist.

Which one should you buy more of?

  • More memory if you keep many apps and browser tabs open, edit large photos or video, run virtual machines, or use local AI models. Memory pressure that's often yellow or red is the sign.
  • More storage if you keep a Photos library, video projects, music libraries, games, or developer tools on the Mac. A disk that keeps filling is the sign. Is 256 GB enough? goes through who needs what.

On Macs with Apple silicon, memory and storage are both part of the chip or logic board. Neither can be upgraded after you buy the Mac, so choose with a few years in mind.

Questions

What's the difference between memory and storage on a Mac?

Memory, or RAM, holds what's open right now and empties when the Mac restarts. Storage, the SSD, keeps your files, apps, and macOS itself, even when the Mac is off. Memory is usually 8 GB or more, and storage 256 GB or more, so storage is the much bigger number.

How do I check memory and storage on my Mac?

Choose Apple menu › About This Mac to see how much memory the Mac has. Open Activity Monitor and click Memory to see how much is in use. For storage, open System Settings › General › Storage.

Why does my Mac say it has run out of application memory?

Usually because apps need more memory than the Mac has, and macOS can't write enough of it to swap on the disk. A nearly full disk makes that more likely. Quit apps you aren't using, and free up disk space.

Does deleting files free up memory?

Not directly. Deleting files frees storage. But if your disk was nearly full, the extra room lets macOS use swap again, which can stop memory warnings.

Should I buy more memory or more storage?

More memory if you keep many apps, browser tabs, or big projects open at once. More storage if you keep large files, like video, photo libraries, or developer tools, on the Mac. On Apple silicon Macs, you can't add either later.
