Install Disk Forecast, a free macOS menu bar app (https://github.com/coreyhaines31/diskforecast), on this Mac:

1. Check that macOS is 14 or later with `sw_vers -productVersion`. If it's older, stop and tell me.
2. If Homebrew is installed (`command -v brew`), run:
   brew install --cask coreyhaines31/tap/diskforecast
   Otherwise, install the latest release from GitHub:
   url=$(curl -fsSL https://api.github.com/repos/coreyhaines31/diskforecast/releases/latest | grep -o 'https://[^"]*\.dmg' | head -1)
   curl -fsSL -o /tmp/DiskForecast.dmg "$url"
   mnt=$(mktemp -d) && hdiutil attach -nobrowse -quiet /tmp/DiskForecast.dmg -mountpoint "$mnt"
   cp -R "$mnt/Disk Forecast.app" /Applications/ && hdiutil detach -quiet "$mnt" && rm /tmp/DiskForecast.dmg
3. Check it's notarized: `spctl --assess --type exec -v "/Applications/Disk Forecast.app"` should say "Notarized Developer ID".
4. Open it: `open -a "Disk Forecast"`.
5. Open the Full Disk Access settings for me:
   open "x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles"
   Then tell me to turn on Disk Forecast there (it's optional), that its drive icon with my free space is now in the menu bar, and that from now on I can ask you why my disk is filling up or what's safe to clear. You'll use the `diskforecast` command (see `diskforecast --help`; if it isn't on the PATH, it's at "/Applications/Disk Forecast.app/Contents/MacOS/diskforecast").

Don't change any other settings and don't delete anything.

Careful by default.

Nothing is deleted without asking, nothing leaves your Mac, and nothing costs a thing.

Trash first

What you clear goes to the Trash, where you can put it back. Delete Immediately and Empty Trash are there when you need the space now, and both ask first.

Apple's own tools

System fixes run tmutil, mdutil, or xcrun simctl, and show you the command first.

Counted once

APFS clones and hard links share space on disk, so they're counted once and totals aren't inflated.

Home folder is enough

Full Disk Access is optional. Cloud drives like Dropbox are never scanned.

Stays on your Mac

No telemetry, no account. The only network call checks for updates, and you can turn it off.

Free. Really.

No trial, no subscription. Source on GitHub, signed and notarized by Apple.

Questions

Is it safe?

Yes. Files it clears go to the Trash, where you can put them back, unless you choose to delete them. Anything an app still has open is left alone. Safe to clear only holds things that rebuild themselves, like caches and build folders. System Data fixes run Apple's own tools, and every one asks you first.

Does it delete anything?

Only when you ask. Cleanup moves files to the Trash unless you choose Delete Immediately, and Empty Trash deletes what's in the Trash, even items Finder can't, like folders whose path is too long. Both ask first. System Data fixes, like removing local Time Machine snapshots, run Apple's own tools after you confirm.

Will it warn me before my disk is full?

Yes. When the forecast says your disk will be full within a week, or space runs low, you get a notification naming what grew most that week and how much emptying the Trash would get back. At most once a day, and you can turn it off in Settings.

Why does it want Full Disk Access?

It doesn't need it. Everything works with your home folder. Full Disk Access lets it measure the folders macOS guards, like Mail, Messages, iCloud Drive, and other apps' containers. Without it, their space shows up as unexplained.

What is System Data?

The catch-all bar in Storage settings for everything macOS doesn't file under a named category: local Time Machine snapshots, purgeable space, simulator runtimes, caches, Apple Intelligence models, the Spotlight index. The guide walks through each one.

How accurate is the forecast?

It's a trend, not a promise, which is why it says “~”. It follows the typical day-to-day change in free space over the last two weeks, so one big download or cleanup doesn't throw it off. It appears after 3 days of history and says how fast space is changing: “Full in ~41 days · using 3.5 GB a day”, “Steady”, or “Free space growing”. When space is low, it says so whatever the trend.

Can my AI agent use it?

Yes. Disk Forecast comes with a diskforecast command, so Claude Code, Codex, or any agent that runs commands can check the forecast, see which folders grew, and list what's safe to clear. It can only move things on the cleanup list, only to the Trash, and shows what it would move until it's told --yes. Homebrew puts the command on your PATH. Every command.

Does it clean up after coding agents?

Yes. It finds the git worktrees Claude Code, Codex, and other agents leave behind and lists each under Worth a look with what removing it would lose: changed files and commits no remote has. Removing one also clears git's records of it, like git worktree remove. Under Safe to clear, it lists what agents download to work: npx packages like MCP servers, older browsers for Playwright and agent-browser, older Claude Code versions, and the temp files Claude Code leaves in /private/tmp after a session, which can reach tens of gigabytes. More on git worktrees.

Why not the App Store?

App Store apps run in a sandbox that can't see most of your disk, so a disk tool there can't measure System Data or run Apple's fixes. Disk Forecast is signed and notarized by Apple, and installs from GitHub or Homebrew.

Is it really free?

Yes, at home or at work. No account, no trial, no subscription. The source is on GitHub, so you can read exactly how it counts and what it moves to the Trash.
