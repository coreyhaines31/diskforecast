For AI agents

Check and reclaim disk space from Terminal, or from your agent.

Disk Forecast comes with a diskforecast command. You, a script, or an AI agent like Claude Code or Codex can get the forecast, see what grew, and move what's safe to clear to the Trash, using the same data as the menu bar.

The short version

Install Disk Forecast with Homebrew and the diskforecast command is on your PATH. diskforecast status shows free space and the forecast, diskforecast changes --days 30 shows which folders grew, and diskforecast cleanup lists what can be reclaimed. diskforecast trash <id> shows what it would move, and --yes moves it to the Trash. Add --json to any command.

The commands

CommandWhat it does
diskforecast statusFree space, the forecast, a low-space warning, and how much is safe to clear
diskforecast changes --days 30Which folders grew or shrank, down to the subfolder, and how much changed outside your home folder
diskforecast cleanupWhat you can reclaim, grouped into Safe to clear and Worth a look, with an ID and explanation for each
diskforecast trash <id or path>Shows what would move to the Trash; add --yes to move it
diskforecast undoPuts back everything the last trash run moved, from Terminal or the app
diskforecast scan --waitMeasures your home folder again and waits until it's done
diskforecast open forecastOpens a window: forecast, cleanup, system-data, or settings

Add --json to any command for output a script or agent can parse. If Disk Forecast isn't running, the command opens it in the background first.

$ diskforecast status
142 GB free of 494 GB (29% free)
Full in ~30 days · using 4.7 GB a day
Safe to clear: 36 GB. See it with: diskforecast cleanup

Install it

Homebrew installs the app and links the command for you:

brew install --cask coreyhaines31/tap/diskforecast

If you installed Disk Forecast from the DMG, open Settings… › General and click Install… next to diskforecast command. macOS asks for your password. Or link it yourself in Terminal:

sudo mkdir -p /usr/local/bin
sudo ln -sf "/Applications/Disk Forecast.app/Contents/MacOS/diskforecast" /usr/local/bin/diskforecast

The command needs Disk Forecast 1.3 or later, and the Install button 1.4 or later, on macOS 14 Sonoma or later. Settings also has a Copy button for the agent prompt below.

Let your agent use it

Paste this into Claude Code or Codex, or add it to your CLAUDE.md or AGENTS.md so it applies every time:

When my Mac is low on disk space, use the `diskforecast` command (run `diskforecast --help`). Start with `diskforecast status` and `diskforecast changes --days 30` to explain what's filling the disk, then `diskforecast cleanup` to see what can be reclaimed. Show me what you'd move and ask before running `diskforecast trash <id> --yes`. Never delete files directly.

Then ask in plain words: “why is my disk almost full?”, “what grew this month?”, or “clear what's safe, but show me first.”

Use it in Claude Desktop

Not using Claude Code? Download diskforecast.mcpb and double-click it, or drag it onto Claude Desktop, and choose Install. Claude can then read your forecast, what grew, and the cleanup list. The extension only reads: moving anything to the Trash stays in the app. More about the extension.

Why it's safe to hand to an agent

  • Only what's on the list. trash takes item IDs and paths from the cleanup list, and refuses everything else, including your Documents, Desktop, and anything outside your home folder.
  • Preview first. Without --yes, it only shows what it would move and how much space that is.
  • Trash, never gone. Everything goes to the Trash. You decide when to empty it.
  • Private. The command talks to the app over a socket only your user account can open, and nothing leaves your Mac.

Without the app: built-in Terminal commands

macOS has its own tools for a quick look. They show the disk right now, not where it's heading:

df -h /                          # free space on the startup disk
du -sh ~/* 2>/dev/null | sort -h   # folders in your home folder, biggest last
tmutil listlocalsnapshots /       # local Time Machine snapshots

Questions

How do I install the diskforecast command?

Install Disk Forecast with Homebrew: brew install --cask coreyhaines31/tap/diskforecast. Homebrew links the command onto your PATH. If you installed from the DMG, open Settings › General in Disk Forecast and click Install, or link it once with sudo ln -sf "/Applications/Disk Forecast.app/Contents/MacOS/diskforecast" /usr/local/bin/diskforecast.

Can Claude Code or Codex use Disk Forecast?

Yes. Any agent that runs shell commands can. Ask it why your disk is filling up, or add a line to your CLAUDE.md or AGENTS.md telling it to use diskforecast when space is low.

Can an agent delete my files with it?

No. diskforecast trash only moves items that are on Disk Forecast's cleanup list, only to the Trash, and only shows what it would move until it's given --yes. Nothing is deleted until you empty the Trash yourself, and diskforecast undo puts back the last run.

Does the command need the app running?

It talks to the Disk Forecast app, and opens it in the background if it isn't running. The app keeps the history the forecast is built from.

How do I check disk space on a Mac from Terminal without an app?

df -h / shows free space on the startup disk, and du -sh ~/* | sort -h lists the folders in your home folder by size. They show the current state, not how fast it's changing.
