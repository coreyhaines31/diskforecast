OnyX alternative

OnyX maintains your Mac. Disk Forecast watches its disk.

OnyX, from Titanium Software, has been a free Mac maintenance utility for more than twenty years. People often install it to get disk space back. It can clear caches and logs, but space is one job among many for OnyX, and the only job for Disk Forecast.

The short version

Use OnyX if you want a free, deep set of maintenance tasks: verifying system files, rebuilding databases and indexes, hidden settings, and cache cleaning, all in one app. Use Disk Forecast if what you want is disk space: a countdown in the menu bar, which folders grew, a cleanup list that explains every item, and everything sent to the Trash. Both are free, and they don't conflict.

What OnyX does well

OnyX has been around since the early days of Mac OS X, and Titanium Software still builds a separate version for each macOS release, back to 10.2. Its own description lists what it does: “verify the structure of the system files; perform cleaning and computer maintenance tasks; uninstall applications; configure parameters in the Finder, Dock, Safari, and some Apple applications; delete caches; remove certain problematic folders and files; rebuild various databases and indexes.”

That's a lot of capability for free, and it's useful when something on a Mac is misbehaving: a Spotlight index that won't finish, a Launch Services database that shows duplicate “Open With” entries, a cache that's gone bad. Most of those tasks need your administrator password, which is normal for tools that touch system files.

Where it stops

Space is a side effect. Clearing caches and logs reclaims some space, and apps rebuild their caches as you use them. We couldn't find a view in OnyX's own materials that shows which folders take the most space or which ones grew.

It runs when you run it. OnyX is a tool you open when you think of it. Nothing tells you ahead of time that the disk is filling, so the first warning is still macOS saying your disk is almost full.

One version per macOS. Titanium Software builds OnyX for each release and says not to use one meant for an earlier macOS. After a macOS upgrade, get the matching OnyX before you run it.

What OnyX does better

Maintenance. Verifying system files, rebuilding databases and indexes, running macOS's maintenance tasks, and changing hidden settings are OnyX's job, and Disk Forecast does none of it.

What Disk Forecast does better

Disk space. It warns you weeks before the disk fills, shows which folders grew and when, explains every item it lists in plain English, and sends what you clear to the Trash, so you can change your mind until you empty it.

Using them together

  1. Install Disk Forecast. brew install --cask coreyhaines31/tap/diskforecast, or download the app from GitHub.
  2. Let it watch. Free space shows in the menu bar right away, and the forecast appears after 3 days of history.
  3. Reclaim space with it when it's time. “Safe to clear” is everything that rebuilds on its own: caches, logs, Xcode DerivedData, and build folders in projects you haven't touched in 30 days. It all goes to the Trash.
  4. Keep OnyX for maintenance. When something misbehaves, like Spotlight or the “Open With” menu, OnyX's rebuild tasks are the right tool. Use the version built for your macOS.

Questions

What is OnyX for Mac?

A free maintenance utility from Titanium Software. Its site describes it as a tool to verify the structure of the system files, perform cleaning and maintenance tasks, uninstall applications, configure hidden settings in the Finder, Dock, Safari, and other Apple apps, delete caches, and rebuild databases and indexes.

Is OnyX free?

Yes. OnyX is free, and Titanium Software accepts donations.

Which version of OnyX do I need?

The one built for your macOS version. As of October 2026, that's OnyX 5.0.6 for macOS Tahoe 26, 4.8.5 for Sequoia 15, 4.6.2 for Sonoma 14, and 5.1.1 for macOS 27. Titanium Software says using a version meant for an earlier macOS is not recommended.

Does OnyX free up disk space?

Some. Clearing caches and logs reclaims space for a while, until apps rebuild their caches. It doesn't show which folders are taking the most space, or which ones grew, so for space it works best alongside an app that does.

Is Disk Forecast free?

Yes, at home or at work, with no account. The source is on GitHub and the app collects no telemetry.
