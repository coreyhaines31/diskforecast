plonge alternative

plonge clears developer caches from Terminal. Disk Forecast tells you when you'll need to.

plonge, by Mattt, is an open-source command-line tool for clearing build folders and package caches after a few weeks of coding agents and git worktrees. Disk Forecast overlaps with its build-folder cleanup from the menu bar, and adds the part plonge doesn't do: telling you when you'll run out.

The short version

Pick plonge if you want one command, on macOS or Linux, that you or your coding agent can run to delete developer caches, with strict git checks before anything goes. Pick Disk Forecast if you want a Mac app that counts down to a full disk, explains everything taking space (not only developer files), and sends cleanups to the Trash. Both are free, and they work side by side.

What plonge does well

Its README starts from a real moment: the disk is full, you need space now, and that's a bad time to delete folders by hand. The folder that looks disposable, it says, “actually had work that hadn't been pushed anywhere yet.”

  • plonge scan lists each build folder with its size, its project, and when the project was last active.
  • plonge clean shows what it would delete, and plonge clean --apply deletes it. By default only projects that have been quiet for 24 hours qualify.
  • plonge clean --global runs each package manager's own cleanup, like uv cache prune and pnpm store prune, and says which ones remove only stale data and which clear everything.
  • plonge mcp lets a coding agent do all of it, with a preview the agent has to show you first.

The checks are the point. A build folder goes only if git ignores it, nothing in it is tracked, no running process has it open, and it holds no git repository of its own, since a cloned dependency can carry commits nobody pushed. It runs on macOS and Linux, and it's open source under the MIT license.

Where it stops

It runs when you run it. plonge can print a warning when a coding session starts, but nothing watches the disk in between or says how many days are left.

Nothing goes to the Trash. What --apply removes is gone. Disk Forecast moves cleanups to the Trash unless you choose to delete right away, so you can change your mind.

Developer files only. Chat attachments, AI models, old downloads, disk images, and System Data aren't its job. On many Macs, those are most of the disk.

It finds projects through mise. By default plonge only scans projects where mise has loaded a config file. Any other project has to be named with --root.

What plonge does better

Depth on package managers. It knows the cleanup command for mise, uv, pnpm, Go, Cargo, Gradle, Maven, NuGet, and more, and it documents what each one can and can't restore. It also runs on Linux, and several of its safety checks are ones Disk Forecast learned from.

What Disk Forecast does better

Telling you ahead of time, covering the whole disk, and keeping cleanups reversible. It lists git worktrees with what removing each one would lose, finds projects anywhere in your home folder without being told where to look, and never needs you to remember to run it.

Using them together

  1. Install Disk Forecast. brew install --cask coreyhaines31/tap/diskforecast, or download the app from GitHub.
  2. Let it watch. Free space shows in the menu bar right away, and the forecast appears after 3 days of history.
  3. See what your agents left. Open Cleanup to find worktrees, build folders, and what coding agents downloaded, each with an explanation. It all goes to the Trash.
  4. Keep plonge for package caches. plonge clean --global prunes the shared caches of the tools you use. Read its dry run first.

Questions

What is plonge?

A command-line tool by Mattt, written in Go and licensed under MIT. plonge scan lists build folders like node_modules, .build, DerivedData, target, and .venv with their size, project, and last activity. plonge clean deletes the ones in quiet projects, and plonge clean --global runs each package manager's own cleanup.

Is plonge safe?

It's one of the most careful tools of its kind. It deletes a build folder only if git ignores it, it holds no tracked files, no running process is using it, and it holds no git repository of its own. Without --apply it only lists what it would delete. What it deletes is gone, though; nothing goes to the Trash.

How do I install plonge?

With Homebrew: brew install mattt/tap/plonge. It also installs through mise or go install, and its releases page has builds for macOS and Linux.

Does plonge work with Claude Code?

Yes. plonge mcp serves its scan, clean, and disk commands to coding agents, it ships a skill file, and plonge disk --warn-below can run as a session hook. Disk Forecast has its own diskforecast command and a Claude extension.

Is Disk Forecast free?

Yes, at home or at work, with no account. The source is on GitHub and the app collects no telemetry.
