Other storage on Mac is now called System Data.

If you're looking for “Other” in your Mac's storage bar and can't find it, it was renamed. If you can still see it, your Mac runs macOS Big Sur or earlier. Either way, here's what's in it and how to reclaim it safely.

The short version

macOS Monterey renamed Other to System Data in 2021, and renamed System to macOS. It's the same catch-all: caches, logs, local Time Machine snapshots, app support files, disk images, and anything macOS doesn't file under a named category. To reclaim it, empty the Trash, clear caches, remove old iPhone backups and disk images, and delete local snapshots with Apple's own tmutil. Don't delete folders in /System or /Library by hand.

What happened to Other storage on Mac?

Until macOS Big Sur, the storage bar in About This Mac › Storage had a gray category called Other. With macOS Monterey in 2021, Apple renamed it System Data, and renamed the old System category to macOS. Nothing about how it's counted changed with the name.

So every guide that tells you to clear Other storage is describing System Data. On macOS Ventura and later, the storage bar lives in System Settings › General › Storage.

What was in Other storage

Other was everything macOS didn't put in a named category:

  • Caches from apps and browsers, in ~/Library/Caches.
  • Logs and crash reports.
  • App support files in ~/Library/Application Support, like chat histories, game saves, and app databases.
  • Disk images and archives: .dmg, .zip, and installers in Downloads.
  • Local Time Machine snapshots, if Time Machine was on.
  • Developer files, like Xcode's DerivedData and simulators.

That's the same list System Data holds today. What is System Data on Mac goes through each part, how big it usually is, and why it keeps growing.

How to delete Other storage, now System Data

  1. Empty the Trash. Deleted files still count until you do. How to empty the Trash.
  2. Clear caches. Apps rebuild what they need. How to clear cache on Mac covers which caches are safe.
  3. Remove old iPhone backups. In Finder, select your iPhone, click Manage Backups, and delete the ones you don't need. Where iPhone backups are stored.
  4. Delete installers and disk images. Sort Downloads by size and move old .dmg and .pkg files to the Trash.
  5. Remove local Time Machine snapshots. Run tmutil listlocalsnapshots / to see them. How to delete local snapshots covers the rest.

The step-by-step version, with Apple's own commands for simulators, the Spotlight index, and more, is how to clear System Data on Mac.

What not to delete

Don't remove folders from /System, /Library, or /private by hand, and don't delete folders in ~/Library/Application Support you don't recognize. That's where apps keep their data, not their caches. Clearing what rebuilds itself is safe. Clearing what an app needs isn't.

Questions

What is Other storage on a Mac?

Older versions of macOS used Other for files that didn't fit a named category: caches, logs, app support files, disk images, archives, local Time Machine snapshots, and system files outside the macOS volume. Since macOS Monterey, the same category is called System Data.

Why can't I find Other storage on my Mac?

Because macOS Monterey renamed it System Data in 2021. Open System Settings › General › Storage and look for the System Data bar.

How do I delete Other storage on a Mac?

There's no single button. Empty the Trash, clear app caches, remove old iPhone backups and disk images you don't need, and delete local Time Machine snapshots with tmutil. Leave the folders in /System and /Library alone.

Is it safe to delete Other storage?

Parts of it. Caches, old installers, iPhone backups you no longer need, and local snapshots can go. System files, app support folders you don't recognize, and anything in /System can't, or shouldn't.

Why is Other storage so big?

Usually local Time Machine snapshots, caches, simulator runtimes for Xcode, or a Docker disk image. The same things make System Data big today.
