Time Machine local snapshots, and how to delete them.

If you back up with Time Machine, your Mac quietly keeps snapshots of itself on its own disk. They're why deleted files don't free space right away, and often why System Data is huge. Here's how to see them and remove them.

The short version

List them with tmutil listlocalsnapshots /. Delete one with tmutil deletelocalsnapshots and its date, like 2026-10-05-093012, or all of them on the startup disk with tmutil deletelocalsnapshots /. Add sudo if macOS refuses. Your backups on the backup disk aren't touched. macOS removes each snapshot after 24 hours, or sooner when space runs low, and makes a new one every hour while automatic backups are on.

What are Time Machine local snapshots?

When Time Machine is set up, it takes a snapshot of your startup disk every hour and keeps it on that disk. A snapshot is a frozen view of every file as it was at that moment. It lets you restore something from this morning even when the backup drive is at home, and it gives Time Machine a consistent copy to back up from.

Snapshots are cheap to make, but they hold on to the past. Delete a 20 GB video after a snapshot was taken, and the snapshot still has it, so the space doesn't come back until that snapshot goes. That's the usual reason a Mac that “should” have free space doesn't.

  • How long they last. macOS removes each local snapshot after 24 hours, and sooner when space runs low.
  • Where they're counted. In System Data in Storage settings, and as purgeable space, so Finder treats them as available.
  • What they aren't. A backup. They're on the same disk as your files, so they can't save you from a failed drive.

How to list local snapshots

tmutil listlocalsnapshots /
tmutil listlocalsnapshotdates /

The first lists snapshots by name, like com.apple.TimeMachine.2026-10-05-093012.local. The second lists only the dates, in the YYYY-MM-DD-HHMMSS form the delete command takes. Both only read. On the Mac this guide was written on, Time Machine has no backup disk set up, and both came back empty: no backup disk, no local snapshots.

To see every APFS snapshot on the data volume, including ones other apps made, there's also diskutil apfs listSnapshots /System/Volumes/Data.

How to delete Time Machine snapshots

  1. Delete one. Use a date from the list: 
    tmutil deletelocalsnapshots 2026-10-05-093012
    The manual says a date deletes the local snapshots with that date on all mounted disks.
  2. Delete all of them on the startup disk. Give it the disk instead of a date: 
    tmutil deletelocalsnapshots /
  3. Or thin them by size. Ask Time Machine to reclaim an amount, in bytes, with an urgency from 1 to 4. This asks for 10 GB at the highest urgency: 
    tmutil thinlocalsnapshots / 10000000000 4
    macOS picks which snapshots to remove to get there.

If tmutil answers with a permissions error, run the same command with sudo in front and enter your password. Your backups on the Time Machine disk are separate, and none of these commands touch them.

Why they come back

Because Time Machine makes a new one every hour. Deleting snapshots reclaims space now; it doesn't change the schedule. Recent versions of macOS dropped the old tmutil disablelocal command, so there's no switch for local snapshots alone. You can:

  • Back up more often. Connect the backup disk regularly, and macOS has less reason to keep snapshots around.
  • Let macOS handle it. When space runs low, it thins snapshots on its own. They're purgeable for a reason.
  • Turn off automatic backups. In System Settings › General › Time Machine. No backups means no snapshots, which is a bad trade on most Macs.

Snapshots are only one part of System Data. For the rest, see how to clear System Data, and for why Finder shows them as free space, purgeable space on Mac.

Disk Forecast and local snapshots

Disk Forecast lists your local snapshots by name in its System Data window. Its Remove local snapshots… button shows you the exact tmutil deletelocalsnapshots command for each date, and runs it only after you confirm. If macOS refuses, it asks for your administrator password and runs the same commands. Your backups on the backup disk aren't touched. It's free.

Questions

How do I delete Time Machine local snapshots?

Run tmutil listlocalsnapshots / in Terminal, then tmutil deletelocalsnapshots with a date from the list, like 2026-10-05-093012. To delete every local snapshot on the startup disk, run tmutil deletelocalsnapshots /. Add sudo if macOS says you don't have permission.

Is it safe to delete Time Machine local snapshots?

Yes. They're extra copies on your Mac's own disk. Your backups on the Time Machine disk aren't touched. You lose the ability to restore from the last few hours while the backup disk is away.

Why do Time Machine snapshots keep coming back?

Time Machine takes a new local snapshot every hour while automatic backups are on. macOS removes each after 24 hours, or sooner when space runs low. Turning off automatic backups stops new ones.

Can I turn off Time Machine local snapshots?

Not on their own. The old tmutil disablelocal command no longer works on recent macOS. Turning off automatic backups stops them, along with the backups.

Where are Time Machine local snapshots stored?

On your startup disk, as APFS snapshots of the data volume. They aren't files in a folder, which is why Finder can't show them. tmutil listlocalsnapshots / lists them by name.

Do local snapshots count as System Data?

Yes. Storage settings counts them in System Data, and macOS counts them as purgeable, so Finder includes them in available space.
