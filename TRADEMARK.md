# Trademark policy

The Disk Forecast code is licensed under the terms in [LICENSE](LICENSE). The **Disk Forecast** name and app icon are not. They identify the official app, so people know what they're installing.

## What's fine

- Saying your project works with, or is based on, Disk Forecast.
- Using the name in articles, reviews, tutorials, and comparisons.
- Building and running Disk Forecast from source for yourself or your team, unchanged.

## What needs a different name

If you distribute a modified version, give it its own name and icon. Don't call it Disk Forecast, use the app icon, or present it as the official app.
